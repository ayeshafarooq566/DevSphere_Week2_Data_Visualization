## DevSphere Internship Program — Week 2

A data visualization project analyzing the Superstore sales dataset using Python, Pandas, Matplotlib, and Seaborn.

## Project Overview

The goal of this project is to analyze sales data and communicate meaningful business insights through clear and professional visualizations.

The project includes:

- Data loading and inspection
- Data quality checking
- Date conversion
- Sales analysis
- Bar chart
- Line chart
- Pie chart
- Business insights
- Reusable visualization code

## Dataset

The Superstore dataset contains:

- 9,994 records
- 21 columns
- Sales information
- Product categories
- Customer segments
- Regional information
- Order and shipping dates
- Profit and discount information

Dataset source:

Kaggle Superstore Dataset
